# АвтоФинансы (Auto Service Finance Management)

Приложение для учёта финансов и задолженностей автосервиса, переписанное на **React + TypeScript + Vite + Tailwind CSS**.

## ✨ Основные возможности

1. **Главный экран (Общий итог)**
   - Наглядные показатели: **Прибыль (Оплачено)**, **Должники (Не оплачено)**, **Траты (Расходы)**.
   - Формула общего баланса: `Прибыль + Должники − Траты`.
   - Быстрый ввод транзакций по кнопкам: «Прибыль», «Траты», «Должники».

2. **Поиск и списание должников**
   - Группировка задолженностей по клиентам и маркам авто.
   - Интерактивный поиск по имени и автомобилю.
   - Частичное и полное списание долга с автоматическим зачислением в прибыль.

3. **Учёт зарплат сотрудников**
   - Ведение списка мастеров и сотрудников с окладом.
   - Выдача зарплаты с автоматическим проведением расхода в финансах.
   - Разворачиваемая история выплат по каждому сотруднику.

4. **Голосовой ассистент**
   - Распознавание команд через Web Speech API и текстовый имитатор голосовых фраз.
   - Умная обработка русскоязычных чисел (цифры и прописью: "три с половиной тысячи", "полтора миллиона").
   - Голосовые команды добавления записей, перехода в отчёт и удаления последних операций.

5. **Финансовый отчёт и экспорт CSV**
   - Фильтрация за период: *Сегодня*, *Неделя*, *Месяц*, *Всё время*.
   - Выгрузка отчёта в формат CSV (UTF-8 с BOM для корректного открытия в Excel).

6. **Темы оформления**
   - 5 цветовых схем: *Синяя*, *Зелёная*, *Фиолетовая*, *Оранжевая*, *Красная*.
